# 智乐融评 · 初中音乐课堂表现性评价工作台

> 面向初中音乐课堂的**表现性评价数智工具**：单文件网页、免安装、免联网、无需账号。

依据 2022 年版艺术课程标准，把「审美感知 / 艺术表现 / 创意实践 / 文化理解」四类核心素养，落到每一节课可操作、可留痕的评价里。

---

## 为什么做这个

音乐课的评价长期卡在两件事上：

1. **留不下痕** —— 一节课 45 人，谁唱得怎样、哪里卡住，全靠老师脑子记，期末写评语基本靠印象；
2. **看不到发展** —— 传统记分只看单次分数，而美育评价真正该看的是**同一个孩子从 72 分走到 85 分的过程**。

这个工具把「量规 + 留痕 + 成长曲线」做成了一页纸的操作界面，老师上课时点几下就能完成一次真实的表现性评价。

---

## 四大模块

| 模块 | 作用 |
| :--- | :--- |
| **课堂评价** | 四维量规逐项打分 + 项目卡切换（演唱 / 演奏 / 听赏）+ A/B/C 判定 + 痛点标签 + 现场手记 |
| **成绩总评** | 全班自动汇总，A/B/C 等第三色比例条，改一个分数实时联动 |
| **班级名册** | 学生档案、个人实测记录、声部与小组归属 |
| **待办事务** | 需要补测、需要复评的学生清单 |

---

## 几个关键设计

### 1. 个人实测 与 小组/声部合作实测 分开

合唱、合奏的课堂形态决定了评价不能只按人头算。工具支持按**声部**（如高声部 / 低声部）和按**小组**两种维度做合作实测——多人共用一把尺，避免把集体成果拆成个人分数。

### 2. 看发展曲线，而不是单次分数

每个学生有一条 SVG 发展曲线：首次 72 → 本次 85，界面直接给出增幅与「攻克徽章」。评价的落点是**成长轨迹**，不是排名。

### 3. 素养诊断小票 + LLM 伴学卡

一次评价结束后可生成「素养诊断小票」：四维得分 → 诊断归因 → 靶向简谱练习卡 → 伴学卡。把评价从课堂延伸到课后，形成闭环，可打印或复制转发给家长。

> 伴学卡部分预留了大模型接入位（DeepSeek 等），用于把「诊断结论」翻译成学生能看懂的具体练习建议。

### 4. 隐私优先：数据不出本机

- 全部数据保存在**浏览器本地存储**，不上传任何服务器；
- 支持一键备份 / 恢复（导出 `.json`）；
- 仓库内这版内置 **45 人虚拟名单**，不含任何真实学生信息。

### 5. 单文件、零依赖、零网络

整个工具就是一个 `index.html`：没有构建步骤、没有 CDN、没有任何网络请求，发一个文件给同事就能用。
这一点是刻意的——一线教室的网络环境不可控，依赖任何在线资源都会让工具在最需要的时刻失效。

## 使用

直接用浏览器打开 `index.html` 即可。首次进入可点顶栏「✨ 载入演示数据」，载入那套 45 人虚拟名单体验完整流程。
