# Display & Game Optimizer (虚拟显示器与游戏调度优化工具)

针对多屏串流（如 Moonlight / Sunshine / 远程桌面）与竞技游戏高刷场景的 Windows 自动化批处理套件。

## 📋 包含脚本

- `enable_virtual_displays.bat` / `disable_virtual_displays.bat`: 基于 PnP 硬件 ID 快速启停虚拟显示器驱动，彻底解决串流黑屏或分辨率不匹配问题。
- `optimize_apply.bat` / `optimize_revert.bat`: 一键优化 Windows 渲染调度、电源计划与高优先级游戏线程，并在游戏结束后无损一键还原。
