# Photo Smart Dedup (智能相册极速双层哈希排重整理器)

基于 **头部+尾部 16KB 采样哈希与完整 MD5 两阶段过滤** 的高性能相册排重工具，专为处理数十 GB 至数 TB 级的家庭照片与视频库设计。

## ⚡ 算法原理

1. **第 1 阶段（极速采样哈希）**：
   - 提取文件大小 + 头部 16KB + 尾部 16KB 进行采样哈希；
   - 避免对大视频（如 4K 视频、几 GB 文件）进行全量读取，能在数秒内过滤掉 99% 的非重复文件。
2. **第 2 阶段（完整 MD5 二次确认）**：
   - 仅对采样哈希一致的疑似文件组进行全量分块 MD5 校验，实现 100% 绝对精确的零误报去重。
3. **拍摄时间轴自动抽取**：
   - 内置智能正则表达式，自动解析主流智能手机（iPhone、华为、小米等）的拍摄命名规范（如 `IMG_YYYYMMDD_HHMMSS`、`wx_camera_*` 等），并自动输出结构化时间轴映射。

## 🚀 使用方法

```bash
python photo_analyzer.py --scan /path/to/photos --output report.json
```
