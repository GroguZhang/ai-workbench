# WeChat PC Migration Toolkit (微信电脑端数据指纹比对与无损合并套件)

用于解决 Windows 换机或多盘重装时，新旧电脑中两份微信数据目录（`WeChat Files` / `xwechat_files`）无法直接覆盖合并的痛点。

## 💡 功能亮点

- **数据指纹比对**：通过文件大小与时间戳采样提取文件指纹，避免重复复制数百 GB 的重复图片与视频。
- **无损合并计划生成**：自动识别仅存在于旧电脑中的历史聊天图片与附件，并生成安全合并迁移计划 JSON。
- **可回滚执行脚本**：提供 PowerShell 执行脚本，支持 Dry-Run 试运行、错误跳过与合并审计日志。
