# 音乐课堂课件（PPT）生成规范

一份**可直接喂给 AI 的硬性约束**，用于生成中小学音乐课堂课件。核心是把「学生看的页面」和「教师看的备课信息」彻底分开，让课件回到它该有的样子——**视听支架，不是电子教案**。

> 由一线中学音乐教师 / 教研组长在真实课堂与教研场景中沉淀，经 20+ 份课件迭代验证。

## 它解决的真问题

AI 生成的课件 90% 是同一个毛病：把「教学重点 / 核心素养 / 设计意图」整块印在投影上，学生看得见、看不懂，教师还得站在旁边重复念一遍。于是课堂变成"朗读 PPT"。

这份规范用一条第一性判断斩断它：

> **出题**：这一行字，屏幕前的初二学生看得懂、且需要看吗？
> 不需要 → 从页面删掉，写进**演讲者备注**。

## 六条核心规则

| # | 规则 | 量化标准 |
|---|---|---|
| 1 | **双轨制**：页面只留四类内容（情境大标题 / 设问短句 / 图谱 / 乐理名词），教研标签全部搬进备注 | 一页正文 ≤ 40 字 |
| 2 | **字号门槛**：投影可读性优先 | 标题 ≥ 32pt，正文 ≥ 24pt，乐理注记 ≥ 20pt |
| 3 | **单点拆页**：学唱环节强制四拆（练声 / 单句谱例 / 动作支架 / 变声期关怀） | 一页一视听焦点 |
| 4 | **留白硬指标** | 文字覆盖面积 ≤ 版面的 30% |
| 5 | **音乐专属可视化**：力度做阶梯图、情绪做渐变条、调式做色卡映射 | 禁止用表格讲力度 |
| 6 | **乐谱与音视频一律留浅灰虚线占位框**，写明去哪儿取 | 全宽 ≥ 1080×140，半幅 ≥ 640×360 |

## 为什么这些约束有效

三条来自真实翻车现场的判断：

- **页数不该被压缩**。45 分钟音乐课拆到 20–25 页是正常量，硬塞进 12 页等于把三个视听焦点糊在同一屏上，学生注意力无处落地。
- **AI 不能编谱**。模型生成的简谱/五线谱错误率高到不可用，规范里直接禁止"自创谱例"，只允许留占位框，由教师粘贴教参原页。
- **备注必须二次注入**。多数 PPT 生成链路（含 SlideDSL 类工具）只把 notes 写进替代文字，PowerPoint 备注窗格完全读不到——教师轨会整体丢失。`SKILL.md` 第 6 章记录了完整的 `inject_notes.py` 修复思路（标准 notesMaster + `ph type="body"` + rels + Content_Types 四处齐补）。

## 使用方式

把 `SKILL.md` 作为系统指令 / Skill 加载，再让 Agent 生成课件即可。`SKILL.md` 末尾附有 9 项**交付前自检清单**，逐项打勾即可验收。

## 适用范围

中小学音乐学科（歌唱课、欣赏课、合唱排练课）。规则中的「拆页逻辑」「留白比例」「可视化映射」可迁移到其他艺术类学科；「字号门槛」「占位框机制」对任何大屏投影场景通用。
