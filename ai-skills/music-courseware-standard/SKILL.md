# 音乐课堂课件（PPT）生成铁律与标准规范

> 由一线中学音乐教师 / 教研组长在真实课堂与教研场景中沉淀的硬性准则。**无条件执行，不因"省事"或"页数好看"而妥协。**

## 0. 第一性判断：课件是给「学生」看的视听支架，不是给「专家」看的电子教案

出题：这一行字，屏幕前的初二学生看得懂、且需要看吗？
- 不需要 → 从页面删掉，写进**演讲者备注**。

---

## 一、双轨制输出（文字搬家原则）

### 1.1 页面正文（面向学生）——只允许保留四类内容
1. 极简情境大标题（≤ 12 字，有画面感）
2. 核心设问短句（≤ 20 字，一句话，**不带标签**）
3. 乐谱 / 图示 / 律动符号
4. 关键乐理名词、发声口诀（短语级，非句子）

### 1.2 页面正文【绝对禁止】出现的教研标签
❌ 教学重点　❌ 教学难点　❌ 核心设问（作为标签出现）　❌ 核心素养
❌ 教学目标　❌ 互动提示　❌ 学情分析　❌ 设计意图
❌ 任何"本页旨在/通过……使学生……"式的教研长句

> 注意区分：设问的**内容**可以留在页面（写成短句），但"核心设问"这个**标签**不许出现。

### 1.3 演讲者备注（Notes）——所有教师向内容全部搬到这里
每页必写，内容包含且不限于：
- 教师话术（逐字可念）
- 设问的引导语、追问链、预期答案
- 学生活动的规则、分组方式、时间控制
- 教参、教材页码范围（来源标注）
- 重难点分析、设计意图、学情提示

写入方式：`<Slide notes={\`...\`}>`，多段用模板字符串换行；用语为第一人称现场口语，不写"本页展示/接下来进入"这类元描述。

### 1.4 字号门槛（适配教室大屏投影）
| 层级 | 下限 |
| :--- | :--- |
| 页面大标题 | ≥ 32pt（建议 36–44pt） |
| 正文 / 歌词 / 口诀 | ≥ 24pt |
| 乐理标签、乐谱注记 | ≥ 20pt |

杜绝长篇大论；一页正文总字数控制在 **40 字以内**为常态，情境页可放宽到 60 字。

## 二、版面呼吸感与结构拆页

### 2.1 摒弃死板的页数限制
45 分钟音乐课件**允许自然扩充到 20–25 页**（学唱课、合唱排练课甚至可到 28 页）。宁可多翻页，不可挤一页。严格践行 **「一页一视听焦点」**。

### 2.2 学唱与重难点必须「单点拆页」（强制四拆）
禁止把"发声提示 + 倚音讲解 + 柯达伊手势 + 旋律线描画 + 乐谱"挤在同一张幻灯片上。必须拆成独立页：

| 拆页 | 页面职能 | 页面只放 |
| :--- | :--- | :--- |
| **页 A** | 微型练声支架 | 基于本课核心动机的母音练声谱（如 Lu / Wu 气息引导），1–2 行谱 + 一句口诀 |
| **页 B** | 单句谱例与引腔 | 大字放大谱例，仅高亮前倚音或衬词「哟」 |
| **页 C** | 动作与视觉支架 | 柯达伊手势实物图示 / 旋律起伏动态波浪线 |
| **页 D** | 变声期关怀提示 | 仅留一两句有温度的艺术发声口诀（如「微声轻抚、高位轻唱」） |

### 2.3 留白比例（硬指标）
**每页文字覆盖面积 ≤ 版面的 30%**，其余 70% 留给意境大图、高清乐谱、律动图示。
自检：把页面上所有文字块面积相加 ÷ 画布面积，超 30% 即返工。

## 三、音乐学科专属视觉支架（听觉艺术具象化）

### 3.1 拒绝通用商务卡片风
色调必须契合音乐艺术美感，按题材选型：
| 题材类型 | 视觉调性 | 色板方向 |
| :--- | :--- | :--- |
| 传统国乐 / 民族器乐 | 典雅宋韵、水墨青绿 | 墨黑 / 青绿 / 宣纸白 / 赭石 |
| 经典红色作品 | 温润暖金与深红 | 深红 `#8C1F1F` / 暖金 `#C09A4E` / 暖白 |
| 现代 / 影视 / 印象派 | 开阔留白与流动线条 | 高留白 + 单一强调色 + 渐变 |

### 3.2 力度与情绪必须可视化（禁止表格文字）
- 力度对比（`mp → mf → f`）→ **视觉阶梯图**（递增高度色块 / 音量柱）
- 情绪递进（如三处「盼」）→ **涟漪扩散图**或**色块渐变条**
- 渐快渐慢 → **疏密不等的律动点阵**

### 3.3 乐理对比必须色彩映射
- 调式色彩（如五声羽调式的暗淡绵长 vs 徵调式明亮）→ **色卡映射**（深青 / 暖黄）+ 对比听辨卡片
- 曲式结构 → **乐段色带**

## 四、音视频与乐谱留空机制（严格执行）

1. 凡涉及**曲谱（简谱/五线谱）、节拍谱、真实原声影视片段、示范唱音频**的位置，一律做成**标准浅灰线框占位符**。
2. 占位符样式统一：`背景 #E8E8E8 ｜ 边框 2px dashed #9A9A9A ｜ 圆角 8–12px ｜ 居中提示图标 + 居中文字`。
3. 文字用**清爽的具体指令**，写清缺什么、去哪儿取：
   - `【乐谱待贴位：教参 PDF 第 27 页】`
   - `【音频待拖入：女声独唱版.mp3】`
   - `【视频待拖入：影片三幕片段·各 20 秒】`
4. 尺寸必须预留充分（全宽横条 ≥ 1080×140；半幅谱例 ≥ 640×360），保证教师本地粘贴原图后**不破坏版面布局**。
5. 不自行创作乐谱（AI 编的谱不可信），也不放任何替代性示意谱充当正式谱例。

## 五、生成后自检清单（每份课件交付前逐项打勾）

- [ ] 页面正文里搜不到：教学重点 / 教学难点 / 核心素养 / 教学目标 / 互动提示 / 学情分析 / 设计意图
- [ ] 每页都有演讲者备注，且包含话术 + 活动规则 + 来源页码
- [ ] 正文字号 ≥ 24pt、标题 ≥ 32pt
- [ ] 每页文字覆盖面积 ≤ 30%
- [ ] 学唱/重难点环节已按"练声 / 单句谱例 / 动作支架 / 变声期关怀"单点拆页
- [ ] 力度与情绪已做成阶梯图 / 渐变条，不是表格
- [ ] 全部乐谱与音视频位置均为浅灰线框占位符，且尺寸留足
- [ ] 全篇页数落在 20–25 页区间（特殊课型可 ±3）
- [ ] 色调与题材匹配（国乐/红色/现代三选一）

## 六、落地流程备忘（Windows）

- 生成链路：SlideDSL 写页面 → `slidep create` 建空白 → 逐页 `lint` → `upsert-dsl` 写入
  → **`inject_notes.py` 二次补备注** → 脚本化验收。
- `slidep` 装在 node 全局包内时不在 PATH，可直接走 JS 入口：
  `<node-dir>\node.exe <node-dir>\node_modules\@tencent\slidep\dist\index.js`
- 在 Git Bash 里跑 Node 脚本时，若报 `dirname: command not found` / `ls: command not found`，
  说明 PATH 被截断，命令前先补齐：
  `export PATH="/c/Windows/System32:/c/Windows:<PortableGit>/usr/bin"`
  脚本内部也不要依赖 `grep/head/tail`，解析 JSON 用 Node 内联。
- python-pptx / lxml 建议装在独立 venv：`<venv>\Scripts\python.exe`（Windows 下是 `Scripts`，不是 `bin`）。
- 截图能力在部分环境不可用；验收改用脚本化检查（见下）。
- **`child-containment` 是硬门禁**，且 slidep 的线盒高度 ≈ `fontSize × 1.2 × lineHeight`。
  例：32px + lineHeight 1.4 → 单行实占 ≈ 53.8px，**不是** 44.8px。容器高度按 `×1.2` 估才安全。
  大字行、多行 `<br/>` 文字行、同心圆图形（子圆直径 > 父容器高）最容易踩雷。

### 6.1 ⛔ 备注必须二次注入（血的教训）
`slidep upsert-dsl` **不生成 notesSlide**。`<Slide notes={...}>` 的文字只会被塞进 spTree 的
`<p:cNvPr descr="...">` 替代文字，**PowerPoint 的备注窗格完全读不到**——双轨制的教师轨会整体丢失。
产物自检：`ppt/notesSlides/` 下应当有 notesSlideN.xml，且 `ppt/notesMasters/notesMaster1.xml`
不能是空壳 spTree（slidep 生成的是没有占位符的空壳，python-pptx 的 `notes_text_frame` 会返回 None）。

修正办法：跑 `_work/inject_notes.py "<pptx>" "<slides目录>"`，它做四件事——
① 用标准 notesMaster（hdr/sldImg/**body**/ftr/dt/sldNum）替换空壳；
② 为每页写 `ppt/notesSlides/notesSlideN.xml`（含 `ph type="body"` 占位符，一段一行）；
③ 给每页 `ppt/slides/_rels/slideN.xml.rels` 加 `notesSlide` 关系；
④ 补 `[Content_Types].xml` 的 Override 声明。
跑完用 python-pptx 复读 `slide.notes_slide.notes_text_frame.text` 确认非空（能读到 = 备注窗格能读）。

### 6.2 交付前跑的三个脚本（都在项目 `_work/`）
| 脚本 | 作用 |
| :--- | :--- |
| `slidep_lintall.js <pptx> <slides目录>` | 只 lint 不写入，快速定位 child-containment 失败页 |
| `slidep_batch.js <项目目录> <pptx名>` | 逐页 lint → 通过才 upsert，打印 ok/失败汇总 |
| `slidep_one.js <pptx> <slide文件...>` | 单页/多页复检，改一页只看一页 |
| `verify_pptx.py <pptx>` | 越界检查 + 占位框计数 + 备注字数 + 字号分布 |
| `check_package.py <pptx>` | OPC 包完整性：XML 可解析 + 关系目标存在 + 内容类型声明齐全 |

**改页顺序**：改 .slide → `slidep_lintall` 定位 → 修 → `slidep create` 重建空白 pptx
→ `slidep_batch` 全量写入 → `inject_notes.py` → `verify_pptx` + `check_package`。
不要用 `upsert-dsl` 单页补写：它是**追加**语义，会把页序打乱。

### 6.3 占位框字号（满足「乐谱注记 ≥20pt」）
主行 32px（=24pt，与正文同档）｜ 副行 27px（=20pt）｜ 副行色 `#8A8A8A`。
放大到 32px 后窄框（≤360px 宽、≤180px 高）会被撑破，需同步把框高提到 ≥200px。
